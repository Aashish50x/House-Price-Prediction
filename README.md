# EstateVal: Premium House Price Predictor 🏡✨

EstateVal is a highly accurate, end-to-end Machine Learning web application that predicts real estate prices across 10 major Indian cities. Powered by a Random Forest algorithm and wrapped in a stunning modern UI, this application evaluates property values based on key factors like location, square footage, property type, and age.

## 🚀 Features

*   **Machine Learning Brain**: Achieves **99.5% accuracy (R-squared)** on synthetic data using an optimized Random Forest Pipeline.
*   **Indian Currency Formatting**: Outputs predicted valuations properly formatted with the Indian Numbering System (e.g., ₹ 1,44,52,898).
*   **Premium Web Interface**: A sleek, fully responsive frontend with glassmorphism, gold accents, smooth animations, and a bespoke real-estate theme.
*   **Live Market Rates Panel**: A custom scrollable widget displaying current average rates across 10 major cities without breaking the aesthetic layout.
*   **Robust Data Pipeline**: Uses `scikit-learn` to seamlessly handle missing values, scale numeric features, and one-hot encode categorical data.

## 📁 Project Structure

*   `generate_data.py`: Creates a highly realistic dataset of 15,000 real estate properties across 10 major Indian cities.
*   `predict_house_price.py`: The machine learning core. It loads the dataset, cleans missing entries, trains Linear Regression, Decision Tree, and Random Forest models, and saves the most accurate pipeline as a `.pkl` file.
*   `app.py`: A local `Flask` web server that loads the trained `.pkl` model, serves the frontend UI on port `8080`, formats output logic, and provides data routes.
*   `house_data.csv`: The compiled dataset generated by `generate_data.py`.
*   `house_price_model.pkl`: The saved Random Forest machine learning pipeline.
*   `templates/index.html`: The gorgeous HTML/CSS structure driving the frontend interface.

## 💻 How to Run It

1. **Install Dependencies**
   Make sure you have all required Python packages installed:
   ```bash
   pip install pandas numpy scikit-learn flask joblib scipy
   ```

2. **(Optional) Regenerate Data and Retrain**
   If you want to recreate the dataset and retrain the machine learning model from scratch:
   ```bash
   python generate_data.py
   python predict_house_price.py
   ```

3. **Start the Web Server**
   Run the Flask backend application (we use port 8080 to avoid macOS AirPlay conflicts):
   ```bash
   python app.py
   ```

4. **Access the App**
   Open your web browser and navigate to:
   👉 **http://localhost:8080**
